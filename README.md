# IT3130 Git Basics Lab

## Purpose
This repository demonstrates a basic Git workflow for IT3130.

## Files
- HelloWorld.html - a small web page used to practise version control
- README.md - project documentation

## Commands practised
git init, git status, git add, git diff, git commit, git log, git remote, git push

## What I learned
Staging lets me review and select exactly which changes go into a commit, instead of committing
everything in the working directory at once. Each commit is a saved checkpoint I can inspect or
return to later. The remote (origin) keeps a synced copy of my history on GitHub, so pushing shares
my commits and lets others (or another machine) pull the same project.
